# Raahi Learning Network — Emotional Design Blueprint V1.4

Status: **DESIGN DIRECTION FROZEN FOR INVESTOR + MARKET READINESS PASS**

## 1. Design objective

Raahi must feel like **a living local learning network**, not an education admin dashboard.

The emotional target is:

**warm + human + local + optimistic + trustworthy + curious**

The product should make a student feel possibility, a parent feel confidence, and a teacher feel respected and discoverable.

## 2. Brand promise

Visible brand:

**RAAHI**  
*Your local learning network*

Raahi Learning Network connects students, parents, teachers and learning organisations within selectable local learning communities. A user may switch Location without changing identity, history or relationships.

## 3. Emotional principles

1. **People before panels.** Human faces, names, goals and achievements should dominate over abstract system states.
2. **Place should be visible.** Dhanbad and Gomoh should feel like real local learning communities, not a filter value in a database.
3. **Every empty state should create momentum.** Never stop at “nothing here”; explain what can happen next and offer a meaningful action.
4. **Learning should feel aspirational, not corporate.** Use warmth, colour, illustration and encouraging language without becoming childish.
5. **Trust remains quiet but obvious.** Verification, privacy and relationship boundaries should reassure users without exposing internal authorization vocabulary.
6. **Activity should be legible.** New teachers, learning requests, events, Community discussions and achievements should make the network feel active.
7. **No fake popularity.** Platform-authored or assisted content must remain distinguishable from organic user activity.

## 4. Visual personality

Keep the existing purple identity, but broaden it into a warmer learning palette rather than replacing it.

Use:

- soft purple/lilac for Raahi identity and primary actions;
- warm amber/yellow for curiosity, opportunity and achievements;
- fresh green for progress, availability and positive status;
- sky/blue accents for information and trust;
- warm off-white surfaces instead of an overwhelmingly white/grey dashboard feel.

Avoid neon gamification, excessive gradients, stock-photo collage aesthetics, or childish classroom clip-art.

## 5. Imagery system

Raahi should introduce imagery deliberately in four layers:

- **Real profile photography:** teacher and organisation photos wherever permission exists. These are the highest-value images because they create trust and humanity.
- **Locality identity:** one subtle visual motif or contextual image per Location where appropriate; avoid making location pages look like tourism pages.
- **Editorial/Community imagery:** optional images for events, achievements, opportunities and Raahi Desk posts when they add information.
- **Illustrated empty states:** lightweight, optimistic illustrations for first-use moments such as no Classes, no Messages or no saved teachers.

Images must never be used to imply that a fictional person is a real teacher, student, parent or customer.

## 6. Avatar and profile rules

Generic initials are fallback only, not the desired steady state.

- Teachers: encourage a clear, friendly real profile photo.
- Organisations: logo or identifiable institute image.
- Students/minors: privacy-first avatar choices; real public photos are never required.
- Raahi Desk: dedicated recognisable Raahi editorial avatar.
- Default avatars: richer illustrated choices with varied age-neutral learning themes rather than flat initials alone.

Profile cards should prioritise **face/logo → name → what they offer/need → locality → trust signals → action**.

## 7. Communication style

Write for normal students, parents and teachers—not for the domain model.

Replace internal language such as:

- “relationship-scoped” → “people and Classes you’re connected with”;
- “public learning options” → “teachers and learning opportunities”;
- “selected Location” when unnecessary → the actual place name;
- “manage learner relationships” → “manage learning profiles”;
- “no current public options” → an encouraging local next step.

Preferred tone: short, encouraging, specific and locally grounded. Avoid hype such as “best”, “top” or unsupported quality claims.

## 8. Locality as a hero element

Location is not merely a filter. It is one of Raahi’s defining experiences.

A locality Home should visibly answer:

- Where am I browsing?
- What can I discover here?
- What is happening here this week?
- Who is teaching here?
- What are students looking for here?
- How do I switch to another Location?

Switching Dhanbad ↔ Gomoh should feel like entering another local learning community while keeping the same Raahi identity.

## 9. Liveness ingredients

Home and Community should feel active through truthful signals such as:

- New in Gomoh / New in Dhanbad;
- teachers currently taking learners;
- genuine learning requests;
- upcoming educational events/opportunities;
- local achievements;
- Raahi Desk questions and guides;
- recently added learning options;
- “this week in learning” editorial summaries.

Do not fabricate counters, urgency, enquiries, reviews, student demand or teacher availability.

## 10. Seeded-content visual contract

Every seed item must carry an origin that is understandable in the UI and analytics:

- `Raahi Desk` — platform-authored editorial/community content;
- `Assisted` — genuine user content entered with Raahi’s help and the user’s consent;
- ordinary user identity — organic content created by the user;
- `Unclaimed listing` — factual public organisation listing awaiting owner claim.

These origins must never be disguised as independent organic users.

## 11. Motion and delight

Use restrained micro-interactions: soft card hover/lift, smooth Location transition, lightweight success confirmation, image fade-in and subtle progress cues.

Do not use confetti for routine actions, infinite motion, autoplay media or animation that distracts from learning. Respect reduced-motion preferences.

## 12. Accessibility and trust guardrails

The emotional redesign must preserve or improve:

- readable contrast and type sizes;
- keyboard/focus states;
- responsive/mobile behaviour;
- alt text for informative imagery;
- privacy controls and current authorization boundaries;
- clear Sponsored labelling;
- clear distinction between verified claims and self-declared information;
- no public minor photo requirement;
- no dark patterns, fake scarcity or engagement manipulation.

## 13. Success test

A first-time user should be able to answer within about 10 seconds:

1. **What is Raahi?** — My local learning network.
2. **Where am I?** — Dhanbad/Gomoh, visibly.
3. **What can I do?** — Find teachers/opportunities, post a learning need, join local learning conversations.
4. **Who is here?** — Real teachers/organisations/community activity, not empty system panels.
5. **Why should I trust it?** — clear identity, locality, privacy and exact trust indicators.

An investor should understand the scalable thesis without narration: **one identity, many local learning networks, switched by Location.**
