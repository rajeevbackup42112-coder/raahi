## 1. Product decisions preserved

V1.3 does **not** reopen the V1.2 domain model. The following remain authoritative:

- Account is distinct from Learner;
- one active managing guardian per Learner in V1;
- no turning-18 migration/lifecycle;
- no public Learner directory;
- active manager owns formal learner-side marketplace/relationship decisions where a manager exists;
- guardian management never grants Test-taking impersonation;
- Enquiry precedes contextual conversation; Trial remains optional;
- Class Invitation precedes Membership and a valid pending invitation reserves capacity;
- one responsible Teacher per Class in V1;
- no attendance, generic progress percentage, public star ratings/reviews, global Community or unrestricted public DM;
- Ads remain education-only, Sponsored-labelled and excluded from private learning/Class/Test/message surfaces.

The principal V1.3 product amendment is authentication/trust UX:

- Google is the intended primary authentication path;
- Google name/photo are editable onboarding defaults, not authority;
- phone verification is intended as periodic trust/contact proof rather than the normal login path;
- stale phone trust must not remove existing learning access;
- anonymous marketplace browsing is deferred rather than required for V1.3.

See `40-final-product-ux-audit-v1.3-draft.md`, `41-authentication-phone-trust-v1.3.md`, `42-v1.3-ui-db-reconciliation.md` and the V1.3 amendment in `07-decision-log-v1.md`.
